# Dinosaur

一个刚起步的仓库。

## 开始使用

```bash
git clone git@github.com:daiyu135/Dinosaur.git
cd Dinosaur
```

## 目录结构

```
.
├── README.md
└── .gitignore
```

## 提交规范（可选）

推荐使用 [Conventional Commits](https://www.conventionalcommits.org/) 风格：

- `feat:` 新功能
- `fix:` 修复缺陷
- `docs:` 文档变更
- `chore:` 构建 / 工具链调整

## 说明

- 默认分支为 `main`。
- `.workbuddy/` 为本地工作区数据，已加入 `.gitignore`，不会上传。
